# Foliate 0.11.2

Foliate 0.11.2 preserves dollar-delimited TeX during Markdown rendering and makes floating tables of contents less intrusive.

## Highlights

- Inline and display TeX enclosed in `$...$` or `$$...$$` now reaches client-side KaTeX without Markdown emphasis parsing corrupting subscripts. Code spans, fenced code, and escaped dollar signs keep their existing behavior.
- Floating tables of contents now have a persistent show/hide control and no longer appear on `_homepage` pages. The control does not shift the sticky table-of-contents alignment.
- CI uses current, SHA-pinned GitHub Actions backed by Node.js 24.

## Upgrading

No configuration changes are required. The first build after upgrading rebuilds every page once so cached pages receive the updated template and stylesheet.
