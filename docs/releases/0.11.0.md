# Foliate 0.11.0

Foliate 0.11.0 adds an optional floating table of contents and fixes list rendering, GitHub Pages Jekyll processing, and stale-cache upgrades.

## Highlights

- `build.floating_toc` config option: pages with headings get a fixed table of contents in the left margin on viewports ≥1320px, rendered from the `toc` extension's output. Off by default; hidden on narrower screens.
- Lists directly following a paragraph (no blank line) now render as proper lists, matching CommonMark/Obsidian behavior (#18).
- `.nojekyll` is written to the build output so GitHub Pages skips Jekyll processing (#16).
- The build schema is bumped: the first build after upgrading does a one-time full rebuild so cached pages pick up the floating TOC and the v0.10.0 autolink changes.

## Upgrading

No migration steps. Expect the first `foliate build` (or watch startup) after upgrading to rebuild every page once.
