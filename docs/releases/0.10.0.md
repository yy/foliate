# Foliate 0.10.0

Foliate 0.10.0 replaces the unmaintained autolink stack with a built-in extension and fixes Quarto asset and wikilink-restore issues.

## Highlights

- Bare URLs with an explicit `http(s)://` scheme are now always linked, including modern TLDs (`.dev`, `.app`, `.google`, ...). The previous `mdx-linkify`/`bleach` pipeline used a pre-2013 TLD list and left those URLs as plain text; bleach is no longer maintained at all (no future releases, including security fixes). The replacement is a small built-in treeprocessor with no TLD list: an explicit scheme is the signal. URLs inside code spans, code blocks, and existing links are untouched, and trailing sentence punctuation stays outside the link.
- Quarto publisher assets are localized in Obsidian previews, and Quarto asset path conflicts are handled during rendering.
- Restoring a private wikilink whose target has since become public now resolves slugified `data-wiki-path` values correctly, instead of leaving the link frozen as a private span.

## Behavior change

Schemeless URL-like text (bare `example.com` in prose) is no longer auto-linked; write an explicit `https://` URL or a markdown link. Scheme-prefixed URLs — the common case in vaults — gain coverage.

## Dependencies

`mdx-linkify` and its transitive dependencies (`bleach`, `webencodings`) are removed.
