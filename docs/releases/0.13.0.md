# Foliate 0.13.0

Foliate 0.13.0 renders more Obsidian syntax: Mermaid diagrams, callouts, highlights, and comments.

## Mermaid diagrams

```` ```mermaid ```` code blocks render to inline SVG at build time with a vendored copy of [Pele](https://github.com/obsidianmd/pele) 1.10.0, the renderer Obsidian uses since 1.15.
Rendering needs `node` on `PATH`.
Without it, or when a diagram fails to parse, the build warns and the block stays a code block.

## Callouts

`> [!type] Title` renders as a box.
`> [!type]- Title` renders as a foldable `<details>` element that starts closed, and `> [!type]+ Title` starts open.
The body is ordinary Markdown, including lists, wikilinks, math, and nested callouts.
Styles ship in `static/callouts.css`.

## Highlights and comments

`==text==` renders as `<mark>text</mark>`; `a == b` with spaces stays as written.

Obsidian comments (`%%text%%`, inline or across lines) are removed before rendering, so their text never reaches page HTML, descriptions, the feed, or the search index.
`%%` stays literal in fenced code blocks, including Mermaid, and in inline code.
An unclosed `%%` hides the rest of the page, as in Obsidian, and the build warns.

## Upgrading

Restart any running `foliate watch` process after upgrading.
The build schema changed, so the first build re-renders every page.

Sites with a custom `.foliate/templates/layout.html` need this line in `<head>`, before the main stylesheet, for callout styling:

```html
<link rel="stylesheet" href="/static/callouts.css">
```

Callouts still fold without it.
